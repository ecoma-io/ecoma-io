# Local Platform — Architecture

> Policy của toàn hệ thống nằm ở [`02-delivery.md`](../../overview/02-delivery.md). File này mô tả ranh giới và bất biến riêng của local platform.

## Ownership

| Resource                     | Owner                 | Ghi chú                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Docker network               | `platform-deploy`     | Mỗi worktree một network                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Traefik container            | `platform-deploy`     | Entrypoint HTTPS duy nhất; image ghim theo digest ≥ 3.6.1 (lý do: Traefik ≤ 3.6.0 ghim Docker API client 1.24, bị daemon mới từ chối — xem comment trong `deploys/platform-deploy/index.ts`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| PostgreSQL + volume          | `platform-deploy`     | Image `timescale/timescaledb` cung cấp sẵn extension TimescaleDB + pgvector, nhưng **chưa enable**: chỉ `POSTGRES_SHARED_PRELOAD_LIBRARIES=timescaledb` được set — deploy unit muốn dùng phải tự `CREATE EXTENSION` trong database **mà nó sở hữu**. Volume `retainOnDelete` — xoá stack không xoá dữ liệu. Instance là shared, database **không**: mỗi deploy unit sở hữu database + role riêng do deploy unit của nó provision (backoffice: `db-backoffice`; identity: `db-account`/`db-auth` — xem [`02-identity.md`](./02-identity.md)); database dùng chung `ecoma_local` chỉ còn là database bootstrap của platform, không consumer nào ứng dụng đọc thẳng |
| Image build + container home | `home-deploy`         | Build bằng `@pulumi/docker-build` (không push registry); routing qua Traefik labels                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Dynamic TLS config           | `platform-deploy`     | File tĩnh `deploys/platform-deploy/traefik-dynamic.yml` bind-mount vào Traefik (file provider) — nguồn duy nhất của TLS store `defaultCertificate`; hardcode tên cert theo `LOCAL_ROOT_HOSTNAME` và bị khóa với hằng số đó bằng spec `traefik-dynamic.yml consistency` (`platform-outputs-contract.spec.ts`)                                                                                                                                                                                                                                                                                                                                                     |

`home-deploy` không tự tạo network/Traefik/PostgreSQL — nó đọc qua Pulumi stack reference tới `platform-deploy` và join network. Hợp đồng outputs (`namespace`, `networkName`, `postgresHost`, `postgresPort`, `traefikHostPort`, `rootHostname`) khai ở `tools/dx/src/deployment/local-platform/platform-outputs-contract.ts`; **không secret nào** nằm trong outputs — password PostgreSQL nằm ở stack config `postgres:password` của `platform-deploy` (local: plaintext; xem mục Invariants).

## Cách ly worktree

Namespace = `w` + 12 hex đầu của xxHash64 trên **absolute worktree root đã normalize** (`tools/dx/src/local-runtime/deploy-namespace.ts`). Mọi tên Docker resource theo mẫu `ecoma-<ns>-<kind>` (ngoại lệ duy nhất: image tag của home là `ecoma-home-<ns>:local`) và tên Pulumi stack (`local-<ns>`) đều mang namespace; state Pulumi là `file://` trong `.pulumi-local-state/` của từng worktree. Hai worktree có thể deploy song song trên một host mà không đụng tài nguyên nào của nhau.

Cách ly còn phủ tới CLI state của Pulumi: mọi lệnh chạy với `PULUMI_BACKEND_URL` trỏ state của worktree và `--stack` đầy đủ `organization/<project>/<stack>` (`tools/dx/src/deployment/local-platform/pulumi-context.ts`) — không `pulumi login` toàn cục; `stack init`/`stack select` của `ensureStack` vẫn ghi workspace file `~/.pulumi` nhưng file đó key theo đường dẫn project nên hai worktree không xung đột, và không lệnh nào _phụ thuộc_ giá trị được ghi đó (fact đo được: `04-platform-facts.md` §2.16 PU12–PU13).

Dockerfile của home nằm ở `deploys/home-deploy/Dockerfile` (deploy unit sở hữu việc đóng gói image), còn build context là **repo root** (pnpm workspace cần lockfile + `libs/ui-ecoma-logo`) — vị trí Dockerfile và build context là hai cấu hình độc lập, mọi path COPY trong Dockerfile là path tương đối với context root. Context được lọc bằng `.dockerignore` ở root: whitelist các path build cần, loại mọi thứ khác — gồm `.env*`, state Pulumi, `.git`, `node_modules`, key TLS — để secret và artifact máy developer không đi vào builder (`tools/dx/src/docker-context.spec.ts` kiểm hợp đồng này).

Routing của Traefik phải lọc theo network của worktree (`--providers.docker.constraints` + label `traefik.docker.network` trên container home): không filter thì Docker provider của **mỗi** Traefik trên host thấy container `traefik.enable=true` của **mọi** worktree qua socket dùng chung, đăng ký router trùng rule `Host(fbi.com)` và request có thể trúng backend ở network không nối tới — treo thay vì lỗi.

## Port và URL

- Chỉ Traefik publish host port: Docker cấp **động**, bind `127.0.0.1` — home và PostgreSQL không publish host port nào.
- `ROOT_HOST` = `fbi.com:<traefik-host-port>`, chỉ suy từ Pulumi outputs sau khi up (`buildRootHost` trong contract). Không hard-code port bao giờ.
- `.env` là **artifact tiện dụng**: orchestration ghi `ROOT_HOST` sau khi đọc outputs (chỉ đụng key mình sở hữu, giữ nguyên byte còn lại), và không chương trình Pulumi nào đọc `.env`.

## Invariants

1. Chỉ Traefik publish host port, và chỉ trên loopback.
2. Volume PostgreSQL sống độc lập với vòng đời container **và** vòng đời stack; đường xoá dữ liệu duy nhất là `pnpm dx local-destroy --remove-data` (in cảnh báo trước).
3. Mật khẩu PostgreSQL local nằm trong Pulumi stack config (`postgres:password`) và bản sao trong `.env`, **không vào Git/log/output/URL**; ở local, stack config lưu **plaintext** (đánh đổi có chủ đích cho môi trường local development — staging/production vẫn dùng secret của Cloudflare Worker); mật khẩu trong stack config và dữ liệu trong volume phải cùng tuổi — destroy **không** `--remove` stack vì đó là cách hai nửa lệch nhau, và deploy fail với hướng dẫn thay vì sinh mật khẩu mới khi config mất mật khẩu nhưng volume còn.
4. Preview và apply tách bạch: `pnpm dx local-deploy --preview` là read-only — không init state/stack, không `config set`/sinh secret, không ghi `.env`, không `up`/`destroy`, và chỉ chạy trên worktree đã apply ít nhất một lần (prerequisite kiểm read-only); Nx target `provision` là dry-run an toàn cho CI (không chạy `pulumi up`).
5. Tên resource luôn qua namespace; không tên nào được suy từ thứ tự chạy hay timestamp.
6. Đổi `LOCAL_ROOT_HOSTNAME` (contract) phải sửa **cùng lúc** `traefik-dynamic.yml`: mount cert suy từ hằng số nhưng TLS store trong file đó hardcode cùng tên — lệch nhau thì Traefik vẫn boot nhưng không có `defaultCertificate` và mọi TLS handshake fail với lỗi không chỉ ra nguyên nhân. Spec `traefik-dynamic.yml consistency` khóa hai phía này với nhau.
